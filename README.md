# 📊 Customer Segmentation using RFM Analysis | Power BI

## Overview

<img width="1175" height="660" alt="Screenshot 2026-08-06 080210" src="https://github.com/user-attachments/assets/f3fc02fe-4d17-4020-b76b-52ff0e631872" />

This project analyzes customer purchasing behavior using the RFM (Recency, Frequency, Monetary) framework in Power BI. The objective is to identify high-value customers, loyal buyers, and customers at risk of churn to support data-driven marketing and retention strategies.

Instead of simply visualizing sales, this project transforms transactional data into meaningful customer segments through data modeling and DAX calculations.

---

## Business Problem

Businesses often have thousands of customers but limited marketing budgets.

Treating every customer the same leads to poor campaign performance.

This dashboard helps answer questions like:

- Which customers generate the highest revenue?
- Which customers purchase most frequently?
- Which customers have stopped purchasing?
- Which customers should be targeted for retention campaigns?

### Dimension Tables

- Date Table
- Customer (RFM Table)

The Date Table enables time intelligence while the RFM table stores customer-level analytical metrics.

---

# DAX Calculations

The following metrics were created using DAX.

### Recency

Number of days since the customer's last purchase.

### Frequency

Number of unique orders placed by the customer.

### Monetary

Total revenue generated by the customer.

These three metrics form the foundation of customer segmentation.
